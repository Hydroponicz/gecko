# Gecko

Third-person open-world crime game built in Godot 4.7 (.NET / C#).

Rise from small-time criminal to kingpin in a 1990s New York-style city:
- **Production chains** — physically build and wire up criminal production facilities.
- **Criminal businesses & heists** — small-time jobs up to major heists, with police heat.
- **Empire building** — recruit and promote crew, take over territory and legit fronts to launder money.

## Branches
- `main` — stable, tested work.
- `preview` — untested new features in progress; merged into `main` once tested.
