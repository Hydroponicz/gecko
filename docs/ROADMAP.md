# Roadmap

One testable slice at a time. Each slice is built on `preview`, tested, then merged to `main`.

1. ✅ **Player** — third-person movement + camera, keyboard/mouse + gamepad.
2. ✅ **Factory gray box** — empty room, placement grid, the four machines, Stash, hand-carrying.
   Also the first on-screen **button prompts** (keyboard / Xbox / PlayStation glyphs).
   Also: **debug menu** (F1 / R3) for testing: give items, refill Stash, game speed, fast-forward.
3. ✅ **Money & supplies** — wallet + bank, physical cash (cash table, duffel bags), pay phones + landlines, supply deliveries.
4. ✅ **Workers** — automatic job split, cap by jobs + building size, game clock, daily wages, pathfinding with fail-safes.
5. **Vehicles & selling**
   - 5a ⏳ (built, awaiting test): drivable sedan, trunk, drive-in loading bay, in-car targeting, gray-box streets.
   - 5b: arrange sales by phone, buyers and distributors, getting paid.
6. **Robberies & street dealing** — starting-money sources.
7. **Police & heat**
8. **Custom DualSense layer** — adaptive triggers, touchpad, HD haptics (USB), our code owns all controller output.
9. **Combat** — guns, melee.

After that: laundering, territory, crew hierarchy, more properties.
